# Merrick Chapel CME Church Website

A responsive, traditional/elegant church website built from the approved Merrick Chapel visual direction.

Includes:
- Responsive desktop/tablet/mobile layout
- Sticky navigation + mobile menu
- Hero worship section
- Pastor profile/message
- About, Worship, Ministries, Events, Media, Giving, Connect, Contact sections
- Modal giving placeholder
- Contact form that opens the visitor's email app
- Exact supplied church logo and CME Connectional Marker
- Exact supplied pastor photography
- Simple editing guide

Open `index.html` locally to preview.
